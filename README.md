# Netflix Dataset Visualization

## Overview

This project analyzes Netflix movies and TV shows using Python and Matplotlib.

## Libraries Used

* Pandas
* Matplotlib
* NumPy

## Visualizations

* Movies vs TV Shows
* Content release trends
* Ratings analysis
* Top producing countries
* Duration analysis
